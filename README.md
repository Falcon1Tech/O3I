# O3I — Osprey 365 Intelligence

A dashboard UI prototype inspired by the approved O3I mockup. This version uses sample/demo data only; Microsoft 365 tenant synchronization, authentication, database persistence, and report automation are not connected yet.


## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

This is a Next.js app suitable for deployment on Vercel after connecting a repository.
